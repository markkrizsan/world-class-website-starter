# 01 — GOVERNING DOCTRINE

## 1. PURPOSE

This file defines the stable reasoning laws governing the World-Class Website OS. It does not define specific visual styles, code techniques, animation libraries, font sizes, section templates, or component patterns.

## 2. EVIDENCE STANDARD

- **OBSERVED** — directly encountered or measured.
- **DOCUMENTED** — explicitly supported by a credible primary or authoritative source.
- **INFERRED [HIGH / MEDIUM / LOW]** — conclusion supported to different degrees but not directly documented.
- **HYPOTHESIZED** — plausible explanation requiring validation.

A pattern is not a law merely because prestigious websites use it.

## G1 — PURPOSE GOVERNS DESIGN

Every consequential website decision must serve what the user needs to understand, feel, decide, or do in service of the project's objective.

Before approving a decision ask:
1. What project/user objective does this serve?
2. What changes if it is removed?
3. Does it improve comprehension, action, emotion, trust, orientation, memory, or brand expression?
4. Is that improvement relevant to this Strategy Vector?

A decision is weak when its primary justification is merely that it looks premium, is trendy, or appears on award-winning sites.

## G2 — COMPLEXITY MUST BE MADE LEGIBLE

As information, visual density, choice, or interaction complexity increases, hierarchy and orientation must increase with it.

Make complexity legible through appropriate combinations of:
- hierarchy
- grouping
- progressive disclosure
- predictable taxonomy
- active states
- user-native mental models
- clear labels
- visual rhythm
- staged sequencing
- fallback navigation
- explicit state change

Prefer organizing complexity around how the user already thinks: outcome, workflow, role, maturity, use case, task, category, business model, implementation path.

Any increase in novelty or complexity creates potential orientation debt. Repay it with semantic, spatial, or procedural clarity.

## G3 — FAMILIAR SEMANTICS BUY CREATIVE FREEDOM

Presentation can become highly unconventional when the underlying meaning remains understandable.

Experiment more freely with how information is presented than with whether users can understand:
- what something is
- what it does
- where it leads
- what state they are in
- how to leave
- how to recover

Preserve semantic anchors such as recognizable labels, meaningful headings, actual links, routes/URLs, predictable controls, accessible text, active states, and explicit close/back behavior.

The more experimental a state transition becomes, the more obvious its reversal should be.

## G4 — STABLE SYSTEMS ENABLE EXPRESSIVE VARIATION

Users should learn the system's rules once. Expression can then vary within those rules.

Stable layers may include component anatomy, grid logic, spacing relationships, navigation behavior, CTA treatment, interaction response, semantic taxonomy, motion grammar, and typography hierarchy.

Variable layers may include imagery, composition, color, scale, atmosphere, illustration, and media treatment.

Goal: consistency without sameness.

## G5 — RESPONSIVE DESIGN PRESERVES VALUE, NOT GEOMETRY

Responsive design exists to preserve purpose, information, usability, identity, and core-value mechanisms across changing conditions. It does not exist to reproduce desktop geometry at smaller dimensions.

The system may reorder, stack, collapse, replace, remove, simplify, crop differently, change navigation, substitute interaction, change motion, or change density.

Ask: what mechanism actually carries the value of this experience? Preserve that mechanism where practical.

Purpose before presentation. Function before literal fidelity.

## G6 — SOPHISTICATION MUST EARN ITS COMPLEXITY

Technical or experiential complexity is not evidence of quality. Complexity is an investment that requires return.

Evaluate value:
- strategic
- communicative
- functional
- brand
- emotional
- commercial

Evaluate cost:
- learning
- UX
- engineering
- runtime performance
- accessibility
- responsive adaptation
- maintenance
- content production
- QA

Always ask whether most useful effect can be achieved more simply.

## G7 — QUALITY IS COHERENCE AT HIGH RESOLUTION

World-class quality is the degree to which strategy, positioning, copy, hierarchy, composition, typography, art direction, media, brand, UI, interaction, motion, responsive behavior, implementation, performance, accessibility, conversion, and micro-polish reinforce one another.

A visually spectacular page with broken mobile states is not world-class. A fast technically clean site with generic art direction is not world-class merely because metrics are good.

## 3. CONDITIONAL RULES BELOW DOCTRINE

Strong but context-dependent rules include:
- novel interaction should communicate unique value;
- progressively conventionalize as user intent becomes more task-specific;
- teach unfamiliar gestures just in time;
- provide conventional fallback navigation for exploratory systems;
- keep primary conversion accessible outside optional experimental interactions;
- place material proof near the claim it validates;
- align conversion friction with buyer commitment/readiness;
- preserve core-value mechanisms on mobile;
- distribute identity across multiple brand materials rather than depending entirely on motion.

## 4. WHAT IS NOT DOCTRINE

Patterns/techniques include giant typography, minimalism, maximalism, custom cursors, WebGL, 3D, parallax, pinned sections, horizontal scrolling, page transitions, preloaders, card layouts, carousels, gradients, grain, serif typography, split screens, and smooth scrolling.

Never elevate them into quality requirements.

## 5. DOCTRINE CHANGE STANDARD

A governing law changes only when meaningful new evidence challenges it, counterexamples are actively sought, causal reasoning is reconsidered, downstream impact is assessed, and the proposed change survives adversarial validation.

## 6. DOCTRINE OUTPUT STANDARD

When invoking a law in reasoning, use the compact form:

`LAW -> CONDITION -> DECISION -> TRADEOFF`
