# EXPERIENCE SPIKE

**No experimental feature enters production solely because it looks impressive. It must demonstrate enough project-specific value to justify its complete system cost.**

## Question

What uncertainty is this experiment trying to resolve?

## Proposed Experience

- feature
- intended user/brand value
- Strategy Vector connection
- governing reference
- motion/interaction job

## Simplest Credible Alternative

What simpler implementation could preserve most of the intended value?

## Prototype Scope

Define exactly what is being tested and what is deliberately excluded.

## Success Criteria

Include when relevant:

- visual quality
- interaction quality
- responsiveness
- touch behavior
- reduced motion
- accessibility
- performance
- browser viability
- maintainability

## Test Environments

- desktop
- mobile
- relevant browsers
- input modes

## Findings

Classify:

- OBSERVED
- INFERRED
- UNKNOWN

## Costs / Risks

- engineering
- performance
- responsive
- accessibility
- maintenance
- content/asset production

## Decision

Use exactly one:

- GRADUATE
- GRADUATE WITH CONDITIONS
- ITERATE
- SIMPLIFY
- REPLACE
- REJECT

## Production Conditions

If graduating, record what must be true before integration.

## Evidence

- screenshots
- recordings
- measurements
- browser results
- related files
