# REFERENCE LOCK

These templates are evidence tools, not moodboards. Their purpose is to prevent abstracting a real reference into generic aesthetic adjectives before implementation.

## Primary Reference

* URL / source
* Why it is primary
* Responsibilities it owns:

  * composition
  * layout architecture
  * interaction architecture
  * navigation
  * section behavior
  * responsive behavior
* Traits we explicitly do NOT intend to copy

## Secondary References

For each:

* Reference
* URL / source
* Exact responsibility
* What may be borrowed
* What must not leak into unrelated parts of the design

## Reference Rules

* One primary reference governs structural/interaction grammar unless explicitly overridden.
* Secondary references contribute named traits only.
* Do not average multiple references into generic “inspiration.”
* Do not copy brand identity, proprietary content, logos, or protected creative assets.
* Reproduce quality and underlying design logic, not another brand’s identity.
* Every deviation from the primary reference should be intentional.
